# Overseas Cricket: social media images

Approved images for Overseas Cricket's Instagram and Facebook posts. They are public only so that Buffer, our scheduling tool, can fetch them when a post goes out.

- Images only: nothing else belongs here.
- Every image is approved by Overseas Cricket before it is added.
- Folders: `instagram/YYYY-MM/`; file names match the post (`date_channel_type_slug_version_slide.jpg`).
